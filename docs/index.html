About Me

안녕하세요! 새로운 기술을 빠르게 익히는 실행력과 끈기를 가진 풀스택 개발자 하혜원입니다.

Java와 Spring Boot 기반의 견고한 백엔드 설계부터 React를 활용한 프론트엔드 UI 개발까지,
데이터의 흐름을 깊이 있게 이해하고 사용자에게 닿는 화면을 직접 구현하는 것에 매력을 느낍니다.

첫째, 직접 부딪히며 익히는 실행력을 바탕으로 새로운 기능을 빠르게 체득하고,
둘째, 원활한 소통과 유연한 협업으로 팀 내 시너지를 이끌어냅니다.
또한, 확실하게 이해하려는 집요함으로 에러의 원인을 끝까지 분석하여 빈틈없이 마무리합니다.

맡은 업무에서 가치를 창출하는 성과를 내는 것은 물론, 팀과 함께 긍정적인 에너지를 나누며
늘 신뢰를 주는 개발자로 끊임없이 성장하겠습니다.
