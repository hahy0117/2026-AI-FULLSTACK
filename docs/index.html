💡 기술적 문제 해결 (Troubleshooting)
문제 이미지 수정 시 DB 부하 및 불필요한 스토리지 I/O
해결

기존 이미지 전체 삭제 후 재저장 대신, 기존/신규 데이터를 비교하여 [유지·삭제·추가] 대상을 분기 처리하는 Diff 로직을 구현해 변경된 데이터만 선별 반영함.

문제 계층형 대댓글 무한 중첩 및 비인가자 삭제 취약점
해결

자기참조(Self-Join) 관계로 설계하되 깊이를 1-depth로 제한해 UI 깨짐을 방지하고, 본인 인증 토큰을 검증해 타인의 임의 삭제 시도를 원천 차단함.

문제 JPA 연관 데이터 조회 시 N+1 쿼리 반복 병목
해결

기본 `FetchType.LAZY`를 유지한 채, 실제 표시에 필요한 데이터는 @EntityGraph를 통한 패치 조인을 적용하여 수십 번의 서브쿼리를 단 1회로 최적화함.
