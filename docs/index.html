Java Console Project

콘솔 기반 뱅킹 시스템 (Bank Project)

Java를 활용해 계좌 등록, 조회, 입금, 출금, 삭제 기능을 구현한 콘솔 기반 뱅킹 프로젝트입니다. 기본 변수 방식에서 배열, DTO와 List를 활용하는 방식으로 단계적으로 확장하며 데이터 관리와 코드 구조를 학습했습니다.

  • ✅ V1 - 기본 변수 방식: 개별 변수를 활용한 단일 계좌 관리
  • ✅ V2 - 배열 방식: 배열을 활용하여 최대 3개의 계좌를 관리하고 ID/Password를 기준으로 계좌 검색
  • ✅ V3 - DTO + List 방식: BankDto로 계좌 데이터를 관리하고 ArrayList를 활용하여 계좌 등록·조회·입출금·삭제 기능 구현
  • ✅ 입출금 처리: 잔액을 확인한 후 입금 및 출금 금액을 반영하도록 구현
  • ✅ 로그인 및 계좌 관리: ID와 Password를 비교하여 사용자 인증 후 계좌 조회 및 관리 기능 수행
